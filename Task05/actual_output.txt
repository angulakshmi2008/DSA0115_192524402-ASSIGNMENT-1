Comparison Analysis:
- Time Complexity: O(1) for both.
- Memory: Expression uses 0 extra bytes; Table uses 24 bytes (sizeof(bool[24]) = 24 bytes).
- Granularity: Expression naturally extends to minutes (hour*60 + minute), while hourly table cannot represent 08:30 without 1440 entries.
